Executive Brief

This is the plain-language version to anchor the conversation before getting into the operational details.

For Adrienne

  • Core value: this turns a one-video-at-a-time editing process into a staggered production system.
  • Capacity gain: the biggest savings show up when one editor runs two or more videos through the system in a batch.
  • Quality control: human review stays in the important places: radio edit cleanup, b-roll approval, and final upload package review.
  • Business impact: each clean export can produce the main platform videos plus podcast audio, preview audio, shorts, transcript, manifest, and description drafts.

For the Editor

  • Start point: run the radio edit pipeline on raw source media and import the generated XML into the NLE.
  • Editor pass: treat the XML as a strong rough cut, not a final edit. Tighten pacing, fix taste issues, and export the clean edit.
  • B-roll pass: run the b-roll pipeline on the clean export, review the generated b-roll, then approve final compositing.
  • Delivery pass: use the clean deliverables folder for upload. Leave working files alone unless troubleshooting is needed.
The system does not replace editorial judgment. It removes repetitive prep and packaging work so the editor can focus on the decisions that actually need taste.

What Each Pipeline Does

The editor is still the editor. The automation removes repetitive prep, assembly, rendering, packaging, and documentation work.

Radio Edit Process

Raw footage to editable rough timeline.

  1. 1
    Create word-level transcriptAssemblyAI gives every spoken word a timestamp.
  2. 2
    Find the clean spoken storyFalse starts, repeated takes, abandoned fragments, and rough phrasing are filtered out.
  3. 3
    Create cut decisionsThe system builds a keep list and supporting audit files.
  4. 4
    Output XML timelineThe editor imports the XML into the NLE and starts from an assembled rough cut.
  5. 5
    Editor fine-tunesThe human pass handles pacing, judgment, taste, and final clean export.

B-roll + Deliverables Process

Clean edit to upload-ready package.

  1. 1
    Analyze clean editCreate or reuse transcript, identify b-roll moments, and build a manifest.
  2. 2
    Generate b-roll clipsMotion graphics are rendered from approved templates, then reviewed before final composite.
  3. 3
    Composite final videosCreate YouTube and Substack versions with the correct chyrons.
  4. 4
    Create derived assetsPodcast MP3, preview MP3, transcript, shorts, manifests, and descriptions.
  5. 5
    Package cleanlyFinal assets go in a deliverables folder; work files stay separate.
The promise is not “push one button and remove the editor.” The promise is “give one editor a strong assembly line so they spend more time on judgment and less time on repetitive setup.”

Human Review Gates

These are the moments where the editor or producer should actively check the work instead of letting the machine run unattended.

1. XML Review Import the radio edit timeline and confirm the spoken story, pacing, and cut choices.
2. Clean Export Check Confirm the clean edit is the right source for b-roll, podcast audio, and descriptions.
3. B-roll Approval Review rendered b-roll clips before final compositing. Revise weak or unclear moments here.
4. Delivery Review Check that the final folder contains only upload-ready files and that descriptions match the current publishing format.

Handoff Shape

The folder structure matters because it keeps finished assets separate from machine work.

Clean Deliverables Folder

This is the folder an editor or producer can select and upload without sorting through internals.

VIDEO_TITLE_DELIVERABLES/
  • final_youtube.mp4
  • final_substack.mp4
  • podcast_full.mp3
  • preview_intro_XXs.mp3
  • shorts_raw_9x16_editorial/
  • transcript.md
  • youtube_description.md
  • podcast_description.md
  • README_MANIFEST.md

Working Folder

This is where the machine keeps the evidence, scratch files, QC material, and intermediate planning.

VIDEO_TITLE_WORKING/
  • raw transcript JSON
  • raw-source transcript
  • shorts EDL records
  • QC stills and audio snippets
  • concat lists and temp files
  • render logs and validation notes
