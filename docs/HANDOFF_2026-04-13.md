## What Is Locked

### Shared baseline

- Background is now charcoal, not blue.
- The `nbj-bullet` brand mark is a shared background asset, pushed off the left edge and shown only partially.
- Accent colors are muted and live in the shared palette.
- This baseline is in [shared.tsx](../remotion/src/broll/shared.tsx).

### `Stack`

- Approved visual system:
  - left-aligned card stack
  - muted borders
  - left role label plus divider
  - no right-side dash
- Approved motion:
  - bottom-up assembly
  - slab reveal first
  - text resolves after the slab lands
  - subtle settle/compression on lower layers
- Special validation rules:
  - 2 to 4 layers only
  - 4-stack has wider role-column handling
  - title/subtitle limits are geometry-aware, especially on narrow lower cards

## Sequence Direction

Working assumption for `Sequence`:

- use for ordered steps, progression through time, or milestone movement
- arrows are allowed here, but only when they are actually doing directional work
- likely visual shape:
  - single horizontal lane
  - 3 to 4 steps max
  - strong left-to-right read
  - text areas with deterministic limits

## Important Constraints

- Never render in parallel on purpose. Chrome conflicts in this repo.
- Keep using tokenized colors for tool calls: `amber`, `cyan`, `green`, `orange`, `purple`, `red`, `steel`.
- Do not let the model invent bespoke diagrams once a template class exists.
- Prefer deterministic validation failure over QA cleanup.
